# MsStatTractor（楓之谷練功追蹤 HUD）

一個給「新楓之谷：經典版」用的練功輔助工具。它用 OCR（光學文字辨識）直接讀取**畫面上**的 LV／HP／MP／EXP 與楓幣數字，幫你追蹤每一段練功的經驗值變化、HP/MP 損失、楓幣增減，以及每分鐘效率與升級預估時間。

**只會「看」畫面，絕不會點擊、輸入或對遊戲送出任何操作，也不讀取記憶體或遊戲檔案。**

---

## 下載與安裝

1. 到 GitHub Release 頁面下載最新版：
   `https://github.com/aaaagent0614-art/MsStatTractor/releases`
2. 解壓縮 `MsStatTractor-版本號.zip`，得到一個 `MsStatTractor` 資料夾。
3. 雙擊裡面的 `MsStatTractor.exe` 即可，**不需要安裝 Python 或任何東西**。

> 資料夾要**保持完整**（執行檔需要旁邊的檔案才能運作），可以整個放到任何位置，例如 `桌面\MsStatTractor`。

> 首次執行時 Windows 可能跳出 SmartScreen 警告（因為執行檔沒有數位簽章），點 **更多資訊 → 仍要執行**。

---

## 快速開始（手動標記模式）

這是搭配放大工具（Magpie 等）時最可靠的方式：

1. 開啟楓之谷（可先開好 Magpie 放大）。
2. 雙擊 `MsStatTractor.exe`。
3. 切到 **設定** 分頁 → 找到 **手動設定位置** → 開啟「**使用手動標記的位置**」。
4. 點「**標記狀態列位置**」，用滑鼠拖曳紅框，框住遊戲左下角顯示 LV／HP／MP／EXP 的那一條。
5. （選用）要追楓幣的話，再點「**標記楓幣位置**」，框住道具欄的楓幣數字。
6. 回 **儀錶板** 分頁，按「**開始**」就會開始記錄。

> 標記的位置會**自動保存**，下次開啟不用重新標。若位置跑掉或讀錯，隨時按儀錶板頂部的「**辨識**」按鈕重新抓取。

## 功能

- **即時追蹤** — LV／HP／MP／EXP 約每秒更新兩次，HP／MP／EXP 都有進度條。狀態標籤會顯示「追蹤中／閒置／偵測中／已暫停／已停止」。
- **紀錄區間（session）** — 數值會依計時器自動重置（預設 10 分鐘，可調 1–60 分鐘）。「經驗值變化」永遠代表「從這段紀錄開始到現在」的變化。
- **暫停／繼續／停止／重新開始** — 暫停時畫面仍持續讀取，但不會計入變化；「停止」會存檔但不再開新段；「重新開始」會提前結束目前區間並（預設）存檔後立刻開下一段。
- **歷史紀錄** — 每段紀錄變成一張卡片，顯示起訖時間、經驗值增減、HP/MP 損失、楓幣變化、EXP/分效率與地圖名稱。**紀錄會自動保存，重開仍在**；可刪除單筆、清空全部、或點標題重新命名。
- **楓幣追蹤** — 開始後開一次道具欄（I）當起始值、結束前再開一次當結束值，兩者相減就是這段時間的楓幣變化（花錢會顯示負數）。
- **地圖欄位** — 儀錶板上有「地圖」欄位，點它就能手動輸入目前地圖名稱，會保存到紀錄卡片與下次開啟。
- **效率（EXP/分）** — 每張紀錄卡片顯示這段時間每分鐘獲得多少經驗值，方便比較練功點效率。
- **升級預估時間** — 累積幾秒資料後，依目前經驗值成長速率估算距離升級還有多久。
- **預估本次經驗值** — 依目前速率推估這段紀錄結束時大概會拿到多少經驗值。
- **設定自動保存** — 標記位置、縮放、語言、各項開關等，重開都會保留。

## 設定說明

| 項目 | 說明 |
| --- | --- |
| 視窗縮放 | 用 +／− 調整整個視窗大小（預設 120%）。 |
| 永遠置頂 | 讓 HUD 蓋在遊戲畫面上方。 |
| 語言 | 中文／英文即時切換。 |
| 紀錄區間 | 每段紀錄多久自動重置（1–60 分鐘）。 |
| 計時結束時自動停止 | 預設開；關閉後時間到會直接接著開始下一段。 |
| 重新開始時儲存至紀錄 | 預設開；關閉後按重新開始只捨棄目前進度、不留紀錄。 |
| 顯示項目 | 個別開關 HP／MP／經驗值／百分比／升級預估／預估本次經驗值。 |
| 楓幣追蹤 | 開關楓幣追蹤（道具欄）。 |
| 手動設定位置 | 標記狀態列與楓幣位置；開啟「使用手動標記的位置」後生效。 |

## 系統需求

- **Windows**（螢幕擷取需要真實的 Windows 桌面）。
- 安裝並執行中的楓之谷（新楓之谷：經典版）。
- **建議解析度 1366×768 以上**，視窗越大文字越清楚、辨識越穩定。

## 疑難排解

- **手動模式按開始卻沒反應** — 你還沒標記「狀態列位置」，程式會跳出提示，不會開始。請先標記，或關掉「使用手動標記的位置」改用自動模式。
- **一直顯示「偵測中」或位置讀錯** — 按儀錶板頂部的「**辨識**」按鈕重新抓取。若位置仍不對，回設定重新標記。
- **所有欄位顯示 `--`** — 自動模式下遊戲視窗需是焦點視窗（遊戲在失去焦點時會降低畫面更新，導致 OCR 讀不到）。手動模式則直接讀你標記的螢幕座標，不受此限。
- **HP／MP 損失看起來不太對** — 請當作大概數字，不是精確統計：程式每秒讀兩次，同一個間隔內扣血又補回的部分看不到；且 OCR 偶爾誤判一次會灌進假損失。經驗值沒有這問題（它只取「結束減開始」，讀錯會自己修正）。
- **楓幣顯示 `--`** — 需要開始後、結束前各開一次道具欄（I）作為起訖值，兩者都有了才會算出變化。
- **數字偶爾停一兩秒才動** — 正常：讀錯的那一幀會被丟掉、沿用上次數值，寧可慢半秒也不要顯示錯誤數字。
